# RLS Policies Migration for Marketplace Columns

## Migration File
`20260527_marketplace_rls_policies.sql`

## Purpose
This migration adds Row Level Security (RLS) policies for the new marketplace integration columns added to the `products` and `orders` tables.

## What This Migration Does

### 1. Products Table RLS
- **Verifies** existing policies cover marketplace URL columns (`shopee_url`, `tokopedia_url`, `padiumkm_url`)
- **Confirms** store owners can update their own products' marketplace URLs
- **Confirms** super admins have full access to all product columns
- **Adds** documentation comments for the new columns

### 2. Orders Table RLS
- **Verifies** existing policies cover marketplace order fields (`marketplace_platform`, `shipping_address`, `shipping_cost`, `platform_fee`, `net_amount`, `province`)
- **Confirms** users can view their own order marketplace fields
- **Confirms** store owners can view orders for their store
- **Confirms** super admins have full access to all order columns
- **Adds** documentation comments for the new columns

### 3. Security Measures
- Ensures RLS is enabled on both tables
- Adds column-level comments documenting the security model
- Provides verification queries to check policy status

## Verification

After running the migration, you can verify the policies are in place:

```sql
-- Check products table policies
SELECT schemaname, tablename, policyname, permissive, roles, cmd
FROM pg_policies 
WHERE schemaname = 'public' 
AND tablename = 'products'
ORDER BY policyname;

-- Check orders table policies
SELECT schemaname, tablename, policyname, permissive, roles, cmd
FROM pg_policies 
WHERE schemaname = 'public' 
AND tablename = 'orders'
ORDER BY policyname;

-- Check column comments
SELECT 
  table_name, 
  column_name, 
  col_description((table_schema||'.'||table_name)::regclass::oid, ordinal_position) as column_comment
FROM information_schema.columns
WHERE table_schema = 'public'
AND table_name IN ('products', 'orders')
AND column_name IN ('shopee_url', 'tokopedia_url', 'padiumkm_url', 'marketplace_platform', 'shipping_address', 'shipping_cost', 'platform_fee', 'net_amount')
ORDER BY table_name, column_name;
```

## Rollback

If you need to rollback this migration, you can remove the comments:

```sql
-- Remove column comments from products table
COMMENT ON COLUMN public.products.shopee_url IS NULL;
COMMENT ON COLUMN public.products.tokopedia_url IS NULL;
COMMENT ON COLUMN public.products.padiumkm_url IS NULL;

-- Remove column comments from orders table
COMMENT ON COLUMN public.orders.marketplace_platform IS NULL;
COMMENT ON COLUMN public.orders.shipping_address IS NULL;
COMMENT ON COLUMN public.orders.shipping_cost IS NULL;
COMMENT ON COLUMN public.orders.platform_fee IS NULL;
COMMENT ON COLUMN public.orders.net_amount IS NULL;

-- Remove table comments
COMMENT ON TABLE public.products IS NULL;
COMMENT ON TABLE public.orders IS NULL;
```

**Note:** This migration does not create new policies, it only verifies existing ones and adds documentation. Therefore, rollback only removes the documentation comments.
